# Arrels de l'Empordà · versión HTML de revisión

Sitio estático (HTML + CSS + JS, sin build). Páginas: `index.html`, `els-nostres-alvocats.html`, `botiga.html`, `la-nostra-finca.html`, `contacte.html` y cinco páginas legales (borradores, sin enlazar desde el pie).

## Publicar en GitHub Pages
1. Sube el contenido de esta carpeta a la raíz de un repositorio.
2. Settings → Pages → Source: *Deploy from a branch* → rama `main`, carpeta `/ (root)`.
3. Tras 1-2 minutos la web queda en `https://<usuario>.github.io/<repositorio>/`.

Imágenes `ph-*.svg` y `cut-pinkerton/fuerte/bacon.svg` son marcadores temporales.
